================================================================================
                          บทนำ (Introduction)
================================================================================

Honeypot คืออะไร?
-----------------
Honeypot คือระบบรักษาความปลอดภัยที่ทำหน้าที่เป็น "กับดัก" หรือ "เหยื่อล่อ"
เพื่อดึงดูดผู้โจมตี (Hacker) ให้เข้ามาโจมตีระบบปลอมของเรา
แทนที่จะโจมตีระบบจริง

ทำไมต้องใช้ Honeypot?
---------------------
1. ตรวจจับการโจมตีแบบ Real-time
2. เก็บข้อมูลพฤติกรรมของผู้โจมตี
3. เรียนรู้เทคนิคการโจมตีใหม่ๆ
4. ป้องกันระบบจริงโดยการเบี่ยงเบนความสนใจ
5. ใช้เป็นข้อมูลสำหรับการวิจัยด้านความปลอดภัย

================================================================================
                    ส่วนประกอบหลัก (Main Components)
================================================================================

1. WEB HONEYPOT (หน้าเว็บปลอม)
------------------------------
- สร้างหน้า Login ปลอมที่ดูเหมือน "Router Admin Panel"
- เมื่อผู้โจมตีพยายาม Login ระบบจะบันทึก:
  * IP Address ของผู้โจมตี
  * Username และ Password ที่ใส่
  * User-Agent (ข้อมูลเบราว์เซอร์)
  * เวลาที่โจมตี
- ทำงานบน Port 8080

ตัวอย่างหน้า Login:
+----------------------------------+
|       Router Admin               |
|   Network Management Portal      |
|                                  |
|   Username: [____________]       |
|   Password: [____________]       |
|                                  |
|        [ Sign In ]               |
|                                  |
|   Firmware Version: 3.2.1        |
+----------------------------------+


2. SSH HONEYPOT (SSH Server ปลอม)
---------------------------------
- จำลอง SSH Server เพื่อดักผู้โจมตี
- บันทึกทุกครั้งที่มีคนพยายาม Login
- บันทึกคำสั่งที่ผู้โจมตีพิมพ์หลังจาก Login
- ทำงานบน Port 2222 (แทน Port 22 ปกติ)


3. LOG COLLECTOR (ตัวเก็บ Log)
------------------------------
- รวบรวม Log จากทุก Honeypot มาเก็บไว้ที่เดียว
- บันทึกในรูปแบบ:
  * JSON File (attacks.json)
  * SQLite Database (honeypot.db)
- ข้อมูลที่เก็บมี:
  * Timestamp (เวลา)
  * Source (WEB/SSH)
  * IP Address
  * Username/Password
  * Command (คำสั่ง)
  * Country/City (ประเทศ/เมือง)
  * Threat Score (คะแนนภัยคุกคาม)
  * Threat Level (ระดับภัยคุกคาม)


4. GEOIP LOOKUP (ค้นหาตำแหน่งจาก IP)
------------------------------------
- ใช้ MaxMind GeoLite2 Database
- แปลง IP Address เป็นข้อมูลตำแหน่ง:
  * ประเทศ (Country)
  * เมือง (City)
  * พิกัด (Latitude/Longitude)
  * Timezone
- ช่วยให้รู้ว่าการโจมตีมาจากที่ไหนในโลก


5. THREAT INTELLIGENCE (วิเคราะห์ภัยคุกคาม)
-------------------------------------------
ระบบจะวิเคราะห์และให้คะแนนภัยคุกคามจาก:

A) การวิเคราะห์รหัสผ่าน:
   - ตรวจจับรหัสผ่านที่ใช้บ่อย เช่น:
     123456, password, admin, root, qwerty
   - ตรวจจับรหัสผ่านที่อ่อนแอ (สั้นเกินไป, ตัวเลขอย่างเดียว)

B) การวิเคราะห์ Username:
   - ตรวจจับ Username ที่นิยมใช้โจมตี เช่น:
     root, admin, administrator, guest, test

C) การวิเคราะห์คำสั่ง (Commands):
   - ตรวจจับคำสั่งอันตราย เช่น:
     * wget, curl (ดาวน์โหลดมัลแวร์)
     * bash -i, /dev/tcp (Reverse Shell)
     * rm -rf (ลบไฟล์)
     * chmod 777 (เปลี่ยนสิทธิ์)
     * /etc/passwd, /etc/shadow (อ่านไฟล์รหัสผ่าน)
     * xmrig, minerd (ขุด Cryptocurrency)

D) การตรวจจับ Brute Force:
   - ถ้ามีการโจมตีจาก IP เดียวกันมากกว่า 5 ครั้งใน 5 นาที
     = ถือว่าเป็น Brute Force Attack

E) การวิเคราะห์ User-Agent:
   - ตรวจจับ Scanner Tools เช่น:
     sqlmap, nikto, nmap, burp, dirbuster


ระดับภัยคุกคาม (Threat Level):
+--------+---------------+------------------------+
| Level  | Score         | ความหมาย              |
+--------+---------------+------------------------+
| LOW    | 0-9           | ภัยคุกคามต่ำ          |
| MEDIUM | 10-19         | ภัยคุกคามปานกลาง      |
| HIGH   | 20+           | ภัยคุกคามสูง          |
+--------+---------------+------------------------+


6. AUTO BLOCKER (บล็อก IP อัตโนมัติ)
------------------------------------
- เมื่อตรวจพบภัยคุกคามระดับ HIGH
- ระบบจะบล็อก IP นั้นโดยอัตโนมัติ
- ใช้ iptables (Linux) ในการบล็อก
- สามารถตั้งเวลาให้ปลดบล็อกอัตโนมัติได้


7. DISCORD ALERT (แจ้งเตือนผ่าน Discord)
----------------------------------------
- ส่งการแจ้งเตือนไปยัง Discord Webhook
- แจ้งเตือนเมื่อพบภัยคุกคามระดับ MEDIUM หรือ HIGH
- ข้อมูลที่แจ้งเตือน:
  * IP Address
  * ประเทศ
  * ระดับภัยคุกคาม
  * รายละเอียดการโจมตี


8. DASHBOARD (หน้าแสดงผล)
-------------------------
- Web Interface สำหรับดูข้อมูลแบบ Real-time
- แสดงสถิติต่างๆ:
  * จำนวนการโจมตีทั้งหมด
  * IP ที่ไม่ซ้ำกัน
  * IP ที่ถูกบล็อก
  * ภัยคุกคามระดับสูง
  * การโจมตีวันนี้
- กราฟแสดง:
  * Timeline การโจมตี 24 ชั่วโมง
  * การกระจายระดับภัยคุกคาม
  * ประเทศที่โจมตีมากที่สุด
  * แหล่งที่มาการโจมตี (Web/SSH)
- ตารางแสดง:
  * Password ที่ถูกใช้บ่อย
  * Username ที่ถูกใช้บ่อย
  * IP ที่ถูกบล็อก
  * การโจมตีล่าสุด

================================================================================
                      การทำงานของระบบ (How It Works)
================================================================================

ขั้นตอนการทำงานเมื่อมีการโจมตี:

1. ผู้โจมตีค้นพบระบบ
   - อาจจากการ Scan Port
   - หรือค้นหาบน Shodan/Censys

2. ผู้โจมตีพยายามเข้าระบบ
   - พยายาม Login ผ่าน Web หรือ SSH
   - ใส่ Username/Password

3. Honeypot บันทึกข้อมูล
   - IP Address
   - Username/Password
   - User-Agent
   - เวลา

4. ส่งข้อมูลไป Log Collector
   - รวบรวมข้อมูลจากทุก Honeypot

5. ระบบวิเคราะห์
   - GeoIP: หาตำแหน่ง
   - Threat Intel: วิเคราะห์ภัยคุกคาม
   - คำนวณ Threat Score

6. บันทึกลง Database
   - เก็บใน SQLite และ JSON

7. ตอบสนองอัตโนมัติ
   - ถ้า Threat Level = HIGH:
     * ส่ง Discord Alert
     * บล็อก IP อัตโนมัติ
   - ถ้า Threat Level = MEDIUM:
     * ส่ง Discord Alert

8. แสดงผลบน Dashboard
   - อัปเดตสถิติ Real-time

================================================================================
                    วิธีการใช้งาน (How to Use)
================================================================================

1. ติดตั้ง Dependencies:
   $ pip install -r requirements.txt

2. ดาวน์โหลด GeoIP Database:
   - ไปที่ MaxMind.com
   - ดาวน์โหลด GeoLite2-City.mmdb
   - วางไว้ใน data/

3. ตั้งค่า Configuration:
   - แก้ไข config/config.yaml
   - ใส่ Discord Webhook URL
   - ตั้งค่า Port ต่างๆ

4. รันโปรแกรม:
   $ python main.py

   หรือรันเฉพาะบาง Component:
   $ python main.py --web-only      # เฉพาะ Web Honeypot
   $ python main.py --ssh-only      # เฉพาะ SSH Honeypot
   $ python main.py --no-dashboard  # ไม่เปิด Dashboard

5. เข้าดู Dashboard:
   - เปิด Browser ไปที่ http://localhost:5000

================================================================================
                        สรุป (Summary)
================================================================================

Honeypot Security System นี้เป็นระบบรักษาความปลอดภัยที่:

1. ล่อดักผู้โจมตี - ด้วย Web และ SSH Honeypot
2. เก็บข้อมูล - บันทึกทุกการโจมตีอย่างละเอียด
3. วิเคราะห์ภัยคุกคาม - คำนวณคะแนนและระดับความเสี่ยง
4. ตอบสนองอัตโนมัติ - บล็อก IP และแจ้งเตือนทันที
5. แสดงผลสวยงาม - Dashboard แบบ Real-time

ประโยชน์ที่ได้รับ:
- เข้าใจพฤติกรรมของผู้โจมตี
- เรียนรู้เทคนิคการโจมตีใหม่ๆ
- ป้องกันระบบจริงได้ดีขึ้น
- เก็บข้อมูลสำหรับการวิจัย
